# ☁️ CloudStore · Frontend

Frontend de **CloudStore**, una tienda con backend desplegado en **Azure App Service**. Permite iniciar sesión y gestionar productos consumiendo la API REST.

![HTML5](https://img.shields.io/badge/HTML5-E34F26?style=flat-square&logo=html5&logoColor=white) ![JavaScript](https://img.shields.io/badge/JavaScript-F7DF1E?style=flat-square&logo=javascript&logoColor=white) ![Azure](https://img.shields.io/badge/Azure-0078D4?style=flat-square&logo=microsoftazure&logoColor=white)

## ✨ Funcionalidades

- **Inicio de sesión** contra `/auth/login`.
- **Gestión de productos:** listar, ver, crear, editar y eliminar (`/productos`).

## 🚀 Cómo verlo

Abre `index.html` en el navegador. La dirección de la API se configura en la variable `API_BASE` dentro del archivo.
